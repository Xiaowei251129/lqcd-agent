# Current state

Updated 2026-11-02. This is the only current capability and qualification record.

## Implemented scope

The development version supports project-based lattice QCD research collaboration over the existing trusted control plane. CLI, Python and the local workbench use one submit/advance path. Protocol/state/execution schema remains `0.4`; scientific artifact schema remains `0.1`.

- Each installation begins with empty `library/wiki`, `library/skills` and `library/methods`. No external private wiki is imported. Versioned candidate/reviewed/contested assets include applicability, source references and operator review receipts.
- Projects have immutable revisions. Runs bind a Project snapshot, input identity and explicitly selected reviewed method versions. Project evidence captures retain registered producer-scoped artifacts and sidecars; they provide readable history without execution/recovery authority.
- Live planning uses PI → Postdoc and review uses independent Reviewer → PI, through the Python OpenAI Agents SDK. The same canonical scientific adapter retains Host numerical checks. All SDK model/tool effects pass the existing budget/fence boundaries; retries, nested agents, SDK sessions and handoffs are disabled.
- Role tools support local library search/reads, candidate creation, full named context reads, project evidence, public INSPIRE metadata and paginated arXiv HTML text. Literature unavailability is explicit; this is not general browsing or figure inspection.
- Questions, responses and references persist through bounded scientific revisions. Concrete PI checks reach coding requirements. Information-dependent plans stop before analysis. Safe revisions use existing replan cycles; numerical warnings, original failure handling, budget stops and final human acceptance remain distinct.
- The independent Codex SDK remains the sole coding backend. Reviewed sources are frozen into read-only coding inputs; final analysis remains a verified self-contained program. Generated code is not automatically promoted to reusable methods.
- C2 and Normalization retain their Host checks. The new `replica_observables` contract binds definitions, units, kinematics and sample identities, checks bootstrap/jackknife arithmetic and always retains limitations concerning physical suitability and original resampling provenance.
- The project workbench provides version-checked edits, investigations, discussions, questions, library inspection, evidence and human decisions. A deterministic final report includes independent review, PI/Postdoc conclusions, Host warnings, remaining questions, human conditions and exact artifact references.
- Existing leases, fencing, idempotency, cancellation, WAL/FULL durability, immutable acceptance, sealed execution and fixed native macOS `/private/tmp` qualification remain in force.
- Research calls use one Agents SDK transport and coding uses one Codex backend. Current artifact fields share one definition; old client parameters, configuration aliases, duplicate schemas/metadata and execution-version compatibility paths have been removed. Unsupported execution layouts are rejected explicitly, and Code projections receive full hash checks.

## Practical limits

Each role currently has two model turns, with at most four model calls per canonical role attempt and the existing Run/replan budgets. Historical issue context is bounded explicitly. New data, physical definitions or incompatible output requirements need a new configured Run; agents cannot silently widen frozen inputs. Arbitrary QCD methods, independent physics validation, large-corpus RAG, HPC and distributed execution are not qualified. Retired Run layouts have no in-place migration; retain their original supported runtime for the original Host.

Method registration verifies exact source/validation bindings and operator decisions, not that arbitrary submitted checks were actually executed or sufficient. Project captures omit raw datasets, control databases, credentials and unregistered failure traces; retain the original Host or use appropriate backups when needed. Cancellation remains available when the data workspace is unavailable; such a response explicitly reports that its Project capture could not be updated. Text paper reading does not inspect figures. Software checks and synthetic calibration do not establish physics readiness.
