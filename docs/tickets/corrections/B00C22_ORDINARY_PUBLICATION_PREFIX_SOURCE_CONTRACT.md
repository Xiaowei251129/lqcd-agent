# C22 Ordinary Publication Prefix Source Contract

C22已通过完整固定当前输入验收并completed；实际证据见独立completion。仅显式trace `0.10` / proof `0.7` 使用本合同，0.1–0.9/default保持原解释和拒绝行为。生产wire/hash/authority/恢复策略不变；本合同不计B04 owned runtime。

`ordinary_publication_prefixes` 是闭合声明集合，每项包含 schema_version、reservation_head、settlement_head、capability_id、producer_operation_id、issuer、journal_revision、journal、publication、stage、snapshot_sha256。每个实际scoped LLM call的actual settlement只能有一个对应声明；actual return必须存在、exception必须null，原settlement唯一、原producer/authorization/Invocation epoch一致。没有completion_intent时，只能声明settled return，不能生成domain artifact或completion。

issuer精确绑定worker_id、invocation_epoch、producer_epoch、producer_revision。journal为profile `invocation_publication_journal` 的canonical源信封，保留原capability的全部实际字段。校验原coordinator中的capability、不可变authorization/started/budget/completion计划、原producer和实际prefix，拒绝缺失、重复、foreign/future owner、重写或伪造返回。合法原suffix发布导致的published标记/状态进展不改变冻结材料；输入与绑定必须仍为原Session。

被动collector将真实读取的journal与publication及当前binding保存到新输出根 `trace_prefix_evidence/<sha256>.json`，声明必须与该实际采集快照逐字节一致，同时通过原coordinator和原文件的独立核验。采集文件不是domain slot、control journal或runtime恢复输入；不能代替原completion，也不能授予effect/closure权限。快照属于本次证据，保留供后续重读。

publication包含execution_head、artifact_history、artifact_index、index_source、projected_members、checkpoint_committed和checkpoint_published。execution与history只能是原授权计划的真实prefix，投影成员须有原canonical namespace/bytes/hash及实际projection文件。checkpoint提交、manifest发布与完整原projection分别核验，不能仅用存在文件证明正确。

index_source=`current_file` 表示采集时实际读取的index；`finished_journal_checkpoint` 仅用于原Invocation已经finished、原completion确已published、原checkpoint及manifest仍可核验的历史index。后续close/advance不能被误解释为该Invocation的index，历史值不能伪装current。Host rejection绑定原frozen failed/error，保留Agent实际返回；不能套用C12 callee-exception receipt。

阶段是从实际journal/publication派生的闭合值：settled_return、completion_frozen、projection_published、history_published、finished_published、index_published、checkpoint_committed、checkpoint_published、host_rejected。每个声明必须有唯一原prefix事件。新projection将已验证阶段、实际projection成员和冻结成员来源绑定到原settlement的semantic digest；不把尚未注册成员加入registered/current集合。domain实际发布后仍使用原Agent→Host诊断/主成员/evidence/dependency校验。原Maximum/exception/unsettled/typed unknown合同复用，不替换、退款或隐式归零。

实际effect停止与authority由原runtime判断。本来源不证明safe stop，不创建Pause/Transition/Run终态；有原frozen completion时只允许原publication端口补exact suffix，无completion或authority不可证明时保持原uncertain/recovery行为，不重复invoke。合法材料或发布阶段变化进入normalized结果；仅原合同已允许的时钟/路径投影保持原行为，不扩大exclusion。

实际实现与验收见[C22 completion](../completions/B00C22_COMPLETION.md)。本票完成后仍须独立复核B04入口，再由B04完成原47/144及全部集成；不保证未来零阻塞。
