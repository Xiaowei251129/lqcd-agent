# Phase D：Agent 能力与物理知识

## Status

`planned`

## 目标

根据可测的能力缺口，逐步增强 Method Planner、Scientific Reviewer 等 Agent，并建立共享、可追踪的 Physics Knowledge Service 和 RAG evaluation。

## 进入条件

- 控制层循环和 Code Agent 已可靠；
- 第一个能力增强试点、evidence bundle 和 benchmark 问题得到确认；
- RAG 不能绕过 deterministic diagnostics、risk floor 或 Human Gate。

## 退出方向

完成后进入 Phase E 综合评估。具体 design/implementation tickets 将在前置阶段完成后创建，本阶段当前没有可执行 ticket。
