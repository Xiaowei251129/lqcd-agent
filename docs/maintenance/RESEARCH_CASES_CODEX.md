# Independent C2 and Normalization case extraction

## Scope and audit

The requested first case set uses existing correlator and fitted-bootstrap inputs without modifying the original analysis project. The operator then required independent programs written by the repository's Codex backend, with normal tools, network access and automatic approval review. The earlier analysis implementation is neither supplied to the programmer nor called for calculations. Existing outputs are withheld comparisons, not certified physics truth.

The original path rejected every SDK tool item, forced tools/network off and disabled permission approvals. It also treated one global coding timeout as independent of the frozen task. Those restrictions prevented normal implementation/testing. Tool activity now comes from the SDK's single event stream and is counted during execution, with completed-item hashes/times bound into delivery evidence. The Host retains its final tree/path validation, stop ownership, write revocation, verification and exact publication.

The case work also exposed an existing semantic-fingerprint defect: ordered multi-clause task requirements were consumed as a canonical set. Only the semantic projection now sorts/deduplicates these strings; immutable task text remains ordered. A real Fake-backend regression exercises code delivery through the scientific Human Gate.

Live retry exposed an overly strict new audit check: the SDK can finish a turn with a started invocation absent from its completed-item list. After verifying process stop, the Host now records that invocation as failed and charges it; it never invents SDK completion. Unknown, altered or missing completed items still fail validation. Regression tests cover both lifecycle outcomes and evidence corruption. The affected trial was canonically canceled before retry.

## Removed and consolidated

- Deleted blanket SDK tool rejection, forced feature/tool disables, unconditional networking prohibition and `ApprovalMode.never`.
- Removed the separate global coding timeout; the worker follows its immutable task deadline.
- Moved duplicate base Git initialization into the existing workspace module for both examples and research fixtures.
- Retained one private input/reference pack and one independent numerical-assessment path. No old analysis-package execution, compatibility alias or fallback sandbox remains.

Initial low-level SDK command execution and an incorrectly scoped temporary-directory profile failed boundary probes. They were discarded/corrected before measured-input execution. Current synthetic checks prove workspace read/write, outside read/write denial and allowed loopback networking. The selected scientific interpreter's launcher symlinks and runtime-library roots are recorded. No core numerical dependency was added.

## Qualification evidence and limits

Four cases cover adjacent-window one/two-state C2 fits, fixed-energy interpretation, complex paired normalization, and physically absent normalization references. Extraction preserves the original IDs/failure masks and binds every source/asset hash. Source-column C2 identity is explicitly distinguished from physical configuration identity. Original normalization resampling-index correspondence remains unavailable.

The initial live pilots produced two successfully sealed, syntax-verified independent programs (C2: 15 SDK tools; Normalization: 13). Earlier trials hit lease/timing limits and were canonically canceled. The two delivered pilot Runs subsequently failed in control progression; those terminal records remain failed. After the semantic-projection and SDK audit fixes, a fresh C2 trial used 17 SDK tools and delivered verified Code to Human Gate. No old Run status was rewritten.

The first calibration also exposed an underspecified output-status enum in the new task specification. The canonical numerical interface is now explicit (`ok`, C2 `partial`, and missing-reference `needs_more_info`); it has no compatibility aliases. Failed assessment reports remain immutable rather than being rewritten.

Initial C2 calibration rejected the program's claim that freely fitting an energy already constituted a completed independent dispersion test, and did not execute measured inputs. The corrected specification was then implemented by Codex, without hand-editing generated code. Final C2 assessment passed hidden two-state calibration, measured one/two-state fits over all windows, withheld one-state comparisons and fixed-energy interpretation. Normalization passed synthetic calibration, every paired complex real-input ratio/percentile summary, withheld real-component comparisons and the physically missing-reference case.

The actual normalization references also exposed a parser mistake during strictness cleanup: their metadata preface precedes the tabular header. The single reader now locates that explicit header and strictly validates all following rows, rather than treating metadata as data or silently discarding malformed data lines. A metadata-preface regression covers this format. Reports bind the complete validator runtime fingerprint as well as the main validator file, so imported parser changes participate in version identity.

Automatic execution review initially rejected network-enabled private-input assessment. Static review of the exact sealed programs established read-only JSON input, stdout output, mathematical imports and no networking, dynamic execution, process spawning or credential access. Execution was then approved on that evidence; the requested network setting was retained.

Detailed source, sandbox, generation and assessment evidence stays in ignored `check-results/`, `raw_data/research_cases/` and owned scratch roots. The assessment records source Run/Code/program/input/validator identities and has no control or acceptance authority. Current complete-suite results belong in [Current state](../REPO_CURRENT_STATE.md).
