# Governance and contract boundaries

Date: 2026-10-27. Audited baseline: `527947f4f094e7e1a37ec446b54d5f63f7faf006`.

## Audit and execution order

The operator authorized dependency/CI maintenance and confirmed dead-code removal first, a separate contract-boundary refactor second, and documentation consolidation last. Permissions, human confirmation, exact publication, lease fencing, SQLite WAL/FULL and immutable scientific evidence remain required throughout.

The baseline had 51 pinned dependencies without reproducible generation or hashes, no static correctness check or CI outcome retention, and a 23-module static strongly connected component including graph state. Replay called private artifact lifecycle functions, and record validation imported graph-owned identities. Audit also found unused memory/read, clock, node-result and schema helpers, two obsolete source-locator tables, and no caller for the alternate Analysis artifact output directory.

## Changes and removals

- One hash-locked `requirements.lock` is generated by pinned uv from `pyproject.toml`, including development tools and a distinct build-tool group. All 51 existing versions are retained. Only uv/Ruff development tools and automatically resolved conditional Windows/Pyodide dependencies are added; the latter do not install in the current macOS environment or expand runtime support. Package hashes and dependency origins are generated, not maintained by hand. Repeating the documented command leaves the lock unchanged.
- Ruff checks explicit syntax/correctness and unused-import rules. Generated protocol code is excluded. Seventeen unused imports were removed without bulk formatting. Tests now import Host lookup from its canonical inspection module; the protocol module explicitly declares its existing public exports.
- CI keeps `contents: read`, pinned actions and disabled live calls. It cancels superseded checks, verifies the lock and dependency consistency, retains the full macOS integration job, and adds Ubuntu static/numerical/wheel checks with runner-owned temporary files. The added artifact action is pinned to its verified v7.0.2 commit. Only outcome summary and detail-free JUnit files are eligible for seven-day retention; local evidence, backend directories and credentials are not uploaded. Build and CI inputs now participate in integration source identity.
- Deleted the unused memory query module, `validate_required_fields`, `allows_edge`, clock `measure`/`ActiveCharge`, the old node-result validator and its field lists, unused graph clock helper, and obsolete locator/projection-root constants. Analysis keeps one canonical output directory; its unused alternate artifact directory and compatibility path rewriting are removed. Allowed commands, program execution, path containment and overwrite protection remain.
- `control/identity.py`, `control/lifecycle.py` and `artifacts/contracts.py` own pure identity formats, execution lifecycle rules and artifact fields/invalidation policy. Replay and artifact validation import those definitions directly. Registry scalar projection has an explicit public function; no compatibility aliases are kept. Six relocated lifecycle implementations are AST-identical after symbol renaming, and all active artifact contract values match the baseline. The static control-to-graph edge count is zero; the largest static component decreased from 23 to 22 modules. Internal control/effect relationships remain, so this is not an acyclic-system claim.
- The 17 declared graph edges, control protocol bytes, serialization formats, authority boundaries and confirmation policy are unchanged. Application build and the source-derived graph fingerprint update with changed source files. No runtime service, extra persistence owner, global cache or automatic approval is added.
- README absorbs the redundant `START_HERE.md`; current state records current support, verification and limits instead of repeating historical acceptance narratives. Prior scoped qualification remains in its original maintenance records and Git history.
