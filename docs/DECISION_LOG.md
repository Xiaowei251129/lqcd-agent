# Engineering decisions

Milestone status belongs in [Current state](REPO_CURRENT_STATE.md).

## 2026-10-28 — canonical generated scientific execution

Connect the existing scientific Planner, CodeHost, fresh Analysis preparation, normal Analysis writer and Scientific Reviewer. Remove fixed research agents, placeholder calculation and separate research workflow profiles. Keep generated programs Run-local and use one sandbox execution primitive and one Host numerical-contract implementation for scientific review and independent assessment. Independent hidden calibration/reference grading does not acquire Run authority.

Freeze JSON input identity, method parameters, code and numerical environment in the existing preparation. Execute under the original resource/lease owner before constructing Analysis evidence. Preserve tool/network availability, SDK automatic review, fencing, budget settlement, WAL/FULL and human scientific confirmation. Treat completed planning separately from unfinished implementation; retain genuine pending plans instead of starting Code. Operator model selection remains in the private ignored `.env`; no model-specific execution branch is added. Keep the existing input-context bound, use the existing request-level Reviewer output allowance, and retain failed incomplete responses. Make Normalization mode tags explicit. Route Ruff caches into the private SDK home and suppress automatic Python bytecode without ignoring unexpected files or restricting tools, networking or automatic review.

## 2026-10-27 — independent research cases and tool-enabled coding

Use the existing Codex backend and durable CodeHost to generate independent C2/Normalization programs from task specifications and synthetic calibration, without supplying the earlier analysis implementation or measured inputs. Enable normal tools, task-authorized networking and SDK automatic approval review as requested. Keep one final Host-validated proposal, actual tool observations, immutable task deadlines and original ownership/stop rules. Remove the blanket tool/network/approval bans and the separate global coding timeout; the worker follows its frozen task timeout.

Keep measured inputs and withheld comparison results in one ignored private case pack. Independent local assessment binds its exact input, program and case-manifest identities and cannot publish scientific acceptance or advance the canonical Run. Use the pinned runtime's explicit sandbox profile with tested outside-workspace denial; an unqualified low-level command API is not an execution path. The original analysis package is a reference source, not the computation engine. Scope and reproduction are in the [case guide](RESEARCH_CASES.md).

Keep network access enabled for the requested workflows, including assessment. Review exact generated source before measured-input execution; retain failed reports and stop before measured inputs if synthetic calibration fails. Remove the duplicated base Git setup and normalize semantic failure-fingerprint sets without rewriting the original ordered task requirements. The audit and remaining checks are in the [maintenance record](maintenance/RESEARCH_CASES_CODEX.md).

## 2026-10-27 — native Mac execution

Use the fixed canonical macOS `/private/tmp` execution parent. Delete retired deployment configuration, environment overrides and admission records. Preserve native writable-local-filesystem checks, private Hosts, boot/PID identity, SQLite WAL/FULL durability, checkpoint validation and human confirmation. Unsupported runtime platforms fail closed; Linux CI remains limited to static/numerical/build checks. Qualification evidence is in the [local record](maintenance/LOCAL_MACOS_QUALIFICATION.md).

## 2026-10-27 — pure contracts and reproducible engineering checks

Keep identities, lifecycle validation and artifact field policy in three small modules without I/O. Move the existing implementations directly; all consumers use their canonical definitions. Keep registry I/O, phase ownership, permission checks, human confirmation and durable publication in their existing owners. Remove unused result/clock helpers, historical source locators and alternate Analysis artifact output projection instead of retaining compatibility branches.

Use pinned uv to generate one hashed environment from runtime/development declarations and an explicit build-tool group. Preserve the existing runtime versions. Apply a narrow Ruff rule set without reformatting the repository. CI retains only bounded outcome reports, with unchanged read-only permissions; Linux static/build checks remain separate from macOS runtime integration. Keep the current-state document current and fold the redundant start page into README. Audit and evidence are in the [maintenance record](maintenance/GOVERNANCE_AND_CONTRACT_BOUNDARIES.md).

## 2026-10-27 — one scientific validator and one publication path

Use the same Host scientific diagnostics in deterministic and provider review. Limit model proposals to interpretation and additive findings; preserve numerical warnings and their confidence ceiling even when model generation fails. Pass validated remediation/history through the existing context bundle, retaining one model call and the current context limit.

Delete unused direct artifact writers and the legacy provider-config factory instead of retaining parallel execution paths. Application assembly owns credentials/live activation; roles accept providers. Reuse immutable ledger snapshots only within a single read or journal validation, refresh after effects, and retain all control fencing and exact publication checks. No global replay cache, new persistence owner, retrieval loop or permission change is introduced. Audit, removed paths and measurements are in the [maintenance record](maintenance/ARCHITECTURE_SIMPLIFICATION.md).

## 2026-10-27 — bounded engineering delivery

Keep the canonical control protocol, permissions, human-confirmation floor and SQLite durability profile. Move deployment resources into the installed package; bind execution to an explicit owned workspace. Use one program descriptor for selection, input mappings and model schemas, and isolate integration examples from scientific assembly. Share closed database schema validation with a read-only inspection path. Keep portable terminal evidence archives separate from database backup and Run recovery, with no extraction, migration or automatic deletion. These choices remove duplicate mappings and source-tree assumptions without introducing another execution or persistence authority. Audit and verification are in the [maintenance record](maintenance/ENGINEERING_DELIVERY.md).

## 2026-10-27 — scientific evidence and minimal model contracts

Bind data identity to immutable Run inputs and to the exact stream consumed by analysis. A digest captured after computation could describe a replacement file, so manifests reuse the observed input record. Explicit absence is also frozen; replay cannot silently admit newly appearing data.

Keep model proposals separate from Host-owned artifact identity and execution metadata. Share one schema between provider output constraints and validation, using `$defs` rather than repeating record definitions. Remove the old LLM Coordinator, executable-mapping repair path, normalization advisories and obsolete tests. Retain the deterministic Coordinator, human-confirmation floor and immutable control protocol.

Store one context evidence bundle per role request, with views over explicitly supplied sources and verified local section reads. Preserve all scientific warnings and task constraints within the existing outbound limit; keep operational scope lists and command logs local. This uses the existing artifact lifecycle without extra model calls, new permission knobs or automatic cross-Run memory. Offline measurements support schema/context simplification; the current microsecond numerical workload does not justify a result cache. No API cache configuration, billing assumptions, concurrency changes or durability relaxation were introduced. Details are in the [maintenance record](maintenance/RESEARCH_EVIDENCE_AND_CONTEXT.md).
